แนวโน้มการระบาดทางระบาดวิทยา (Epidemic Curve - Epi Curve)

วิเคราะห์อัตราการเจ็บป่วยตามช่วงเวลาเพื่อประเมินสถานการณ์ระบาด

ระยะเวลาประมวลผล: รายเดือน/รายสัปดาห์

ตารางสรุปสถานการณ์ระบาดจำแนกรายจังหวัด

ค้นหา กรองข้อมูล และส่งออกรายงานสำหรับการทำวิจัยหรือสรุปเสนอผู้บริหาร

ลำดับ จังหวัด ภูมิภาค ผู้ติดเชื้อสะสม กำลังรักษา หายแล้ว เสียชีวิต ระดับความเสี่ยง การจัดการ

ระบบแดชบอร์ดสนับสนุนการตัดสินใจระบาดวิทยาโรคติดต่อ (Epidemiological Decision Support System)

ออกแบบสำหรับนักวิชาการสาธารณสุข และเจ้าหน้าที่ EOC • รองรับการอัปโหลดไฟล์ชุดข้อมูลของกระทรวงสาธารณสุข

พัฒนาด้วย Leaflet (Esri World Tile Service), Chart.js และ Tailwind CSS • พร้อมสำหรับ GitHub Pages Deployment

ขั้นตอนการอัปโหลดขึ้น GitHub Pages

  1. สร้าง Repository ใหม่: ไปที่ GitHub.com/new ตั้งชื่อคลังข้อมูล เช่น covid19-dashboard-thailand
  2. บันทึกและอัปโหลดไฟล์ HTML: บันทึกไฟล์นี้ในชื่อ index.html แล้วเลือกคำสั่ง Upload files บนหน้า GitHub Repository
  3. เปิดใช้งาน GitHub Pages: ไปที่แท็บ Settings → เมนูด้านซ้ายเลือก Pages → ตรง Build and deployment เลือก Source เป็น Deploy from a branch และเลือก Branch เป็น main / root กด Save
หลังจากทำครบ 3 ขั้นตอน คุณจะได้ URL เว็บไซต์แดชบอร์ดสาธารณสุขเปิดแชร์ให้ทีมงานเข้าดูได้ทันที!
